# 🎓 Online Course Management System

A simple and user-friendly **Online Course Management System** developed using HTML, CSS, and JavaScript. The project allows users to explore courses, manage their profile, track progress, and interact with course-related features.

## 🚀 Features

* 🔐 User Sign Up and Sign In
* 🏠 Interactive Home Page
* 📚 Browse Available Courses
* 🔍 Search and Filter Courses
* ➕ Add and Edit Courses
* 👤 User Profile Management
* 📊 Course Progress Tracking
* 🏆 Certificate Generation
* 💾 Data Storage using Local Storage
* 📱 Responsive Design
* 📞 Contact and About Us Pages

## 🛠️ Technologies Used

* **HTML5** – Structure and content of the web pages
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Dynamic functionality and user interactions
* **Local Storage** – Storing user and course-related data in the browser

## 💡 How It Works

The application provides different pages for managing and accessing online courses.

1. **Sign Up** – Users can create an account.
2. **Sign In** – Registered users can log in.
3. **Dashboard** – Users can access their course-related information.
4. **Courses** – Users can view available courses.
5. **Search & Filter** – Courses can be searched and filtered easily.
6. **Progress** – Users can track their learning progress.
7. **Certificate** – Users can generate/view course completion certificates.
8. **Profile** – Users can manage their profile information.

The project uses **Browser Local Storage** to store data, so no external database or backend server is required.

## ▶️ How to Run

1. Clone the repository:

```bash
git clone <https://github.com/NomithaPathivada/Online_Course_Management_System>
```

2. Open the project folder.

3. Open `index.html` in a web browser.

4. For the best development experience, open the folder in **Visual Studio Code** and use the **Live Server** extension.
